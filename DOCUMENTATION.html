R6 Codex – Technische Dokumentation

R6 Codex ist eine hochperformante, moderne Web-Applikation zur Visualisierung und Durchsuchung von Spieldaten aus Tom Clancy's Rainbow Six Siege. Diese Dokumentation bietet Entwicklern und Benutzern einen tiefen Einblick in die Systemarchitektur, den mathematischen SVG-Parser und die Interaktionssysteme.

Interactive Maps

18 Maps mit präziser Raumsuche, mobilem Pinch-to-Zoom und pulsierenden Ortungs-Pings.

Operator & Vergleich

Umfassende Statistiken zu allen 70+ Operators mit dynamischem Side-by-Side-Vergleich.

Waffen-Schadenskurven

Visualisierung des Schadensabfalls (Damage Drop-off) über Distanzdiagramme für alle 118 Waffen.

Tech-Stack & Projektstruktur

Die Applikation nutzt Next.js SSG (Static Site Generation), um extrem kurze Ladezeiten zu erzielen. Sämtliche Steckbriefe und Kartendaten werden zur Build-Zeit in statisches HTML übersetzt.

Interactive Map-Viewer & Multi-Touch

Das Herzstück des Kartensystems ist der in MapFloorViewer.tsx implementierte Canvas/Image-Viewer.

💡 Mobiles Pinch-to-Zoom & Pan

Auf Touchscreens wird das gleichzeitige Zoomen und Verschieben über Pointer Events abgefangen. Durch die Verwendung lokaler Koordinaten relativ zum Map-Container verbleibt das Zoomzentrum stabil direkt unter den Fingern.

So funktioniert die Gesten-Berechnung

Beim Ansetzen zweier Finger (Multi-Touch) wird der Startabstand der Finger \(d_{start}\) und der Startmittelpunkt \((cx_{start}, cy_{start})\) registriert. Bewegen sich die Finger, wird der Skalierungsfaktor über das Verhältnis der aktuellen Distanz zur Startdistanz ermittelt:

factor = current_distance / start_distance;
next_scale = clamp(min_scale, start_scale * factor, max_scale);

Die Karte wird anschließend so verschoben (Pan), dass der Berührungspunkt auf dem Kartenbild exakt an der Position des neuen Mittelpunkts verankert bleibt: 

t.current.scale = nextScale;
t.current.tx = cx_current - ((cx_start - tx_start) / scale_start) * nextScale;
t.current.ty = cy_current - ((cy_start - ty_start) / scale_start) * nextScale;

Operators & Waffen-Datenbank

Die App bietet ein durchsuchbares Register aller Operators und Waffen. Alle Loadout-Einträge sind dynamisch verknüpft.

Operator-Vergleich (Compare-Engine)

Unter /compare können zwei Operators direkt nebeneinander geladen werden. Ein Client-seitiges Skript filtert und stellt die Unterschiede in Gesundheit, Rüstung, Spezialfähigkeiten sowie Primär- und Sekundärwaffen übersichtlich dar.

Waffen-Schadenskurve

Für jede Waffe wird die Schadensabfallkurve (Damage Drop-off) visuell dargestellt. Ein SVG-Graph berechnet aus den Distanzwerten der Spieldaten (z. B. 0–18m voller Schaden, linearer Abfall bis 28m, danach konstanter Minimalschaden) ein flüssiges Kurven-Diagramm:

Mehrsprachigkeit & Übersetzungs-Pipeline

R6 Codex implementiert ein nahtloses System zur Übersetzung großer Datenmengen.

Da Ubisoft-Spieldatenbanken meist nur auf Englisch vorliegen, übersetzt das Skript translate-db.mjs die gesamte Quelldatenbank R6_complete.json vor dem Build-Prozess.

Resilienz: Um Abbrüche bei Netzwerkproblemen oder API-Limits zu verhindern, nutzt das Skript ein automatisiertes Retry-Verfahren mit exponentiellem Backoff (Exponential Backoff):

Wartezeit = Startzeit * 2 ^ (Versuch - 1) + Jitter
i18n Pipeline Workflow
1. Englisch (R6_complete.json) laden
⬇️
2. API-Übersetzung (DE & FR)
⬇️ Bei Fehler: Retry mit Backoff
3. Export: R6_complete_de.json

SVG Coordinate Solver

Präzision & Mathematik

Das Einzoomen auf Räume in Vektorgrafiken stellt eine Herausforderung dar, wenn Räume innerhalb verschachtelter, transformierter Gruppen deklariert sind.

Der Raumkoordinaten-Parser traversiert die XML-Struktur der SVG-Dateien und führt einen Stack (Kellerspeicher) für die Transformationsmatrizen.

Trifft der Parser auf eine Gruppe mit transform, wird diese Matrix mit der bisherigen kumulierten Matrix multipliziert. Jede Textkoordinate wird anschließend durch diese Gesamtmatrix in absolute globale Koordinaten übersetzt.

// Matrix-Multiplikation im Parser
a_neu = a1 * a2 + c1 * b2
b_neu = b1 * a2 + d1 * b2
c_neu = a1 * c2 + c1 * d2
d_neu = b1 * c2 + d1 * d2
e_neu = a1 * e2 + c1 * f2 + e1
f_neu = b1 * e2 + d1 * f2 + f1

Entwickler-Befehle & Dev-Guide

Zur Ausführung der Entwicklerwerkzeuge und Kompilierung nutzen Sie die folgenden Befehle:

1. Entwicklungs-Server starten

npm run dev

2. Spieldaten übersetzen

node scripts/translate-db.mjs

3. Linter ausführen

npm run lint

4. Production Build kompilieren

npm run build
